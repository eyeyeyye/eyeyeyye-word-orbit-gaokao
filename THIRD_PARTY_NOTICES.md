# Third-party notices

This project was rebuilt from scratch. It does not contain code or content copied from an earlier version of the user's site.

Vocabulary enrichment uses data freshly processed for this project from:

- ECDICT, an English–Chinese dictionary database, MIT License: https://github.com/skywind3000/ECDICT
- english-vocabulary, public vocabulary JSON data used for cross-checking example sentences and word families: https://github.com/KyleBing/english-vocabulary
- Ministry of Education, *English Curriculum Standards for Senior High Schools (Experimental, 2003)*, used as historical scope evidence. The source says “approximately 3,500 words,” not an official frozen list containing exactly 3,500 rows.

The 300 phrase ranking is an editorial study priority for the 2021–2025 exam cycle. It is not an official frequency table issued by the National Education Examinations Authority. The phrases and Chinese study notes are included as educational metadata; full exam papers are not redistributed.

The 200 continuation-writing sentences, explanations, memory prompts and generation formulas are original project content.
