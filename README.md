# Word Orbit · 高考英语学习舱

一个从零制作、纯静态、无需登录的高考英语学习网站。输入网址即可打开；词汇、短语、续写句和学习进度都在浏览器本地运行，不依赖境外 API。

## 内容

- 恰好 3,500 个冻结词条：中文释义、英/美音标、浏览器朗读、例句、词形、词族、介词用法与搭配
- 恰好 300 个高考常用短语：按 2021–2025 学习优先级排序，并明确该排名不是考试院官方统计
- 恰好 200 个原创读后续写高质量句：翻译、亮点、记忆钩子和仿写公式
- 本地间隔复习、每日目标、连续学习、搜索、收藏、进度统计、JSON 导入导出

## 本地检查与构建

需要 Node.js 18 或更高版本：

```bash
npm run check
```

构建完成后，`dist/` 是可直接交给 Manus 或静态托管平台的成品目录。

## 部署

本项目没有后端、数据库、登录或环境变量。可把仓库根目录交给 Manus，也可以直接部署 `dist/`。若要保证中国大陆访问，最终仍需选择可在大陆直连的托管服务并对真实网址进行外网验证；代码本身没有 Google Fonts、海外 CDN 或境外接口依赖。

## 内容口径

教育部 2003 课标使用“约 3500 词”的表述，2020 修订课标又采用新的分级词汇口径，因此不存在一个全国现行、官方发布且精确到 3500 行的唯一清单。本项目从本轮新获取的高考标记词池中，按词频、词典完整度和学习价值冻结为恰好 3,500 条，并在 `public/data/content-meta.json` 记录方法和限制。
